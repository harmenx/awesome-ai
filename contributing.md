# Contribution Guidelines

Pull requests are welcome. If you know of a great AI / ML tool or dataset, open an issue or a pull request.

Please ensure that:

- The tool or dataset is actively maintained and widely used.
- You provide a brief description and a link.
- Affiliate links are clearly marked.
- Entries use this format: `- [Name](link) - Description.`
- The description starts with an uppercase character and ends with a period.
- Search existing entries before adding one.
- Check spelling and grammar.
- The pull request has a useful title.

Thank you for your suggestions.
